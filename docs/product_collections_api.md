# API подборок товаров

Подборка хранится отдельно от бренда, категории и цены. Связь с товаром —
`product_collections(product_id, collection_id)`; одна карточка может входить в
несколько подборок.

## Получение подборки для сайта

`GET /api/v1/site/collections/<slug>/products?limit=200`

Ответ содержит активную опубликованную подборку и только активные товары ERP:

```json
{
  "data": {
    "collection": {"id": 1, "name": "WOW-цена", "slug": "wow-price"},
    "products": [{"id": 42, "name": "...", "brand": "...", "category": "..."}]
  },
  "meta": {},
  "error": null
}
```

Системные slug: `wow-price`, `bestsellers`, `new`, `preorder`, `sale`.
Endpoint только читает данные и не меняет товар. Он использует действующую
авторизацию ERP; для внешнего сайта следует настроить защищённый server-to-server
доступ на уровне reverse proxy или отдельного API-токена. Код витрины находится
вне этого репозитория, поэтому переключение пункта «WOW-Цена» на этот контракт
нужно выполнить отдельно на стороне сайта.
