## Контрактная проверка

Наличие handler подтверждено route manifest, UI — наличием template, logic/data —
вызовами services/schema, tests — ссылками в таблице. Для трёх подозрительных
templates выполнен read-only lookup через Jinja loader: все три отсутствуют.
Это проверяет template contract без внешних API и записей данных. Остальные
модули подтверждены существующими unit/test-client tests; production behavior
этим не утверждается.
