## Критические stop-ship условия

Release/migration останавливается при любом из следующих условий:

1. необъяснимое отличие в stock, money, sale/receipt items, external IDs, users/roles или file checksums;
2. CSRF/permission bypass, secret in bundle/log, unredacted PII or unauthorized file access;
3. duplicate/partial external write without deterministic reconciliation;
4. failed restore rehearsal or unmeasured rollback duration;
5. visual/function matrix row without accepted parity;
6. API/frontend schema incompatibility;
7. production build/deep-link/API routing smoke failure;
8. required test or migration check failure.

## Review cadence

- Пересматривать register при каждом stage planning и после любого production incident.
- Critical/high risks имеют named human owner, due date, evidence link and residual rating before enabling a route.
- `UNKNOWN/BLOCKED` не понижаются по предположению: требуется read-only evidence или rehearsal.
- Risk acceptance для data loss, auth/security, external writes и destructive migrations принимает владелец бизнеса совместно с technical/security owner.
